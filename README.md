# Churn Model Project 

## Overview

The purpose of this churn model project is to **reduce the churn rate among customers** by building predictive models that identify customers at risk of leaving. This project uses machine learning techniques to analyze customer behavior and patterns to help implement targeted retention strategies.

## Project Goals

- Build accurate predictive models to identify customers likely to churn
- Analyze key factors contributing to customer churn
- Provide actionable insights for customer retention
- Develop a framework for monitoring and predicting future churn

## Getting Started

### Prerequisites

- Python 3.7+
- Jupyter Notebook
- Required packages (see `requirements.txt`)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Y-jones/Churn-model-project-GROUP-8.git
cd Churn-model-project-GROUP-8
```

2. Install required dependencies:
```bash
pip install -r requirements.txt
```

3. Open Jupyter Notebook:
```bash
jupyter notebook
```
